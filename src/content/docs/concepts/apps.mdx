An **app** gives people a view of authorized domain data and the work the team can do with it. A built-in Studio grid or board describes a view over a list. A custom app can show a chart, call scoped connector operations, or consume results from agents.

## Definitions and installations

A built-in view is declared as a team resource. A custom app package contains its manifest and compiled interface. Its installation binds the package to workspace data and permissions. An externally hosted interface calls the authorized app bridge for those operations.

For example, a prospect board can display the current pipeline stage. A custom dashboard can chart how many prospects are waiting for a reply, using the same records.

See [built-in views and custom apps](../records-and-apps/#built-in-views-and-custom-apps) and [custom app packages](../../apps/#6-custom-app-packages-).
