A **lifecycle hook** runs at a point the harness defines. Gabriel playbook packages can declare `BeforeTask` and `AfterTask` in the skill folder’s `gabriel/hooks.json`.

## Check inputs and results

A before hook can validate a playbook’s declared inputs before its work begins. An after hook can check the declared output before the result counts as complete. For example, a playbook can require that an output include a source identifier before another step uses it.

Studio shows executable hook commands during package review. Installed hooks run bundled Node.js scripts in a verified, isolated Studio computer. A failed check stops progression. Connector access and approval to perform an external effect are checked separately.

See [code execution](../code-execution/), [packaging and installation](../packaging/), and [Standard Agent Specification’s hook lifecycle](https://standardagentspec.org/0.2.0/specification/hooks/).
