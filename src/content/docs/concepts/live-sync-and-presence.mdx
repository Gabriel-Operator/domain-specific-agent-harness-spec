**Live sync** keeps open views current as workspace records and run state change. **Presence** shows which members are active, such as their current view or cursor. These features use the workspace’s access controls.

## Events and shared views

When a playbook publishes an accepted field change, the runtime can notify clients that may read the affected list. A board can then show the new stage without a reload. Presence can show who is looking at that board. In Gabriel Studio, following another member mirrors their view while the follower’s own permissions still apply.

The Apps and connectors profile documents Gabriel’s live event transport and proposes shared presence behavior.
