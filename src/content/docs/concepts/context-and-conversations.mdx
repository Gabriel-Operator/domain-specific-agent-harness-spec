**Context** is the material a team can draw on, such as a shared brief, organization knowledge, or an accepted output. A **conversation** is the exchange of messages between people and authorized agents. Both are workspace data and can be subject to different access grants.

## Carry useful context into a run

A goal can use a team brief and the outputs it is allowed to read. In Gabriel Studio, a person can edit a shared page while an agent maintains a live section or proposes an addition. In a team conversation, a member can address a specific agent by tagging it.

For example, a prospect’s shared brief can hold accepted research while an outreach discussion asks one agent about a reply. A portable persona can define the workflow that uses these sources. The installation keeps the actual pages, messages, and revisions.
