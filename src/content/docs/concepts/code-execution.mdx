**Code execution** runs a script in an environment provisioned for the task. The harness supplies the input, controls the resources available to the script, and collects its result.

## Run code with a defined boundary

In Gabriel Studio, packaged lifecycle hooks use a fresh, verified E2B computer with Node.js installed. The harness passes the declared fields to the script over standard input. The hook environment has outbound networking disabled and runs without workspace credentials or a connector broker. Missing compute requires setup. A failed check stops progression.

A [sandbox rehearsal](../sandbox-rehearsal/) serves a different purpose. It produces evidence about how a proposed action would behave with a test account, mock, or copy before a person approves a live effect.

See [lifecycle hooks](../hooks/), [packaging and installation](../packaging/), and [Standard Agent Specification’s isolated code execution](https://standardagentspec.org/0.2.0/specification/threads/code-execution/).
