An **execution receipt** records evidence of what happened after dispatch. A provider may return a delivery ID, a confirmed order, or an identifier for the record it updated. Keep the receipt with the run and the approval it consumed.

## Handle an uncertain result

If a network failure interrupts a response after dispatch, reconcile the outcome against the provider before trying again. The provider may have accepted the request. A rehearsal records expected behavior in isolation. A live receipt records the actual effect.

Paya checks for a merchant order ID before recording a purchase as complete. An uncertain payment is reconciled before another charge can be attempted.
