An **approval** authorizes an exact effect within a run. It identifies the operation, destination, material inputs, acting account, and applicable policy. The approval belongs with the run and the proposal the person reviewed.

## Before dispatch

Show the actual proposed effect and any relevant rehearsal evidence. Wait for the authorized person, then check the current grants and confirm that the action still matches the reviewed proposal. A changed recipient, amount, or account calls for a new proposal. Rejection or expiry holds dispatch.

For an outreach email, confirming the goal lets preparation begin. The send approval covers the actual sender, recipient, and message. The runtime consumes it once and keeps the result with the run.
