Use **Marketplace** in Studio to find published playbooks, teams, and personas. Filter by package type or enter the exact registry, name, and version. An installation preview shows the resolved dependencies, the destination, required connector operations, and any executable hooks.

A workspace owner applies the reviewed installation. The destination team configures its own connections, output destinations, spending limits, and approvals before running a goal. Use the **Installed** view to preview an update or removal. A private release can be installed by exact reference using registry credentials.

See [package formats](../packaging/) and [publishing from Studio](../../implementation/#build-and-install-from-a-blank-canvas).
