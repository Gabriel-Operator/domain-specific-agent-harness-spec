## Package, agent, workspace

- **Package.** The Git repository you version and share. Gabriel Operator calls this a *persona*.
- **Agent.** The worker that uses instructions and tools. A package can define a team of agents.
- **Workspace.** An installation that holds accounts, records, permissions, and run history.

See [Terms and standards](./standards/) for the glossary and how Agent Skills, MCP, and A2A fit.

<span id="anatomy-of-a-persona"></span>

## Inside the package

[**`SKILL.md`**](./specification/#2-skillmd-) provides instructions. [**Definition files**](./specification/#6-definition-files-) describe the data and workflows. The [**registry**](./specification/#5-registry-) pins the Git revision and fingerprint of each linked definition.

<span id="how-does-a-persona-work"></span>

## From Git to a running workspace

A runtime [checks the package on import](./specification/#5-registry-), binds what the installation needs, and [reports which steps it can execute](./specification/#71-capability-report-).

Draft 0.1 comes from packages running on **Gabriel Operator**. The [Portable Persona Runtime](https://github.com/Gabriel-Operator/portable-persona-runtime) is a self-hosted implementation.
