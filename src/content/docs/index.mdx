## Package, agent, workspace

<div class="ap-terms not-content">
  <div><span>01 / Definition</span><strong>Package</strong><p>The folder you review, version, and share. Gabriel Operator calls this a <em>persona</em>.</p></div>
  <div><span>02 / Execution</span><strong>Agent</strong><p>The worker that follows instructions, uses tools, and can run a playbook. A package can define a team of agents.</p></div>
  <div><span>03 / Installation</span><strong>Workspace</strong><p>The environment where the package is installed. It holds accounts, records, permissions, and run history.</p></div>
</div>

<span id="anatomy-of-a-persona"></span>

## Inside the package

The root [Agent Skills](https://agentskills.io/specification) file provides instructions. JSON definitions describe the work and the data it uses. The registry pins the Git revision and fingerprint of each linked definition.

## From Git to a running workspace

A compatible runtime checks the package on import, supplies what the installation needs, and reports which steps it can execute.

<Flow />

The draft comes from packages running on **Gabriel Operator**. The [Portable Persona Runtime](https://github.com/Gabriel-Operator/portable-persona-runtime) is a self-hosted implementation. Check each runtime's capability report before running a package.
