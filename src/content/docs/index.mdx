## Persona, runtime, and harness

- **Playbook.** Reusable work that can be discovered in a marketplace and referenced by teams.
- **Persona.** The versioned composition of a domain model, teams, and their playbooks.
- **Goal.** An outcome scoped to a team. It can invoke saved playbooks and guide the authoring of new ones.
- **Runtime.** The layer that loads a persona, connects it to workspace resources, and coordinates execution.
- **Agent harness.** The system that runs the agent loop and coordinates model calls and tool use.
- **Workspace.** An installation that holds accounts, records, permissions, and run history.
- **Domain specialist.** The person who defines what good work looks like, resolves anomalies, and reviews changes to the rules.

See [Terms and standards](./standards/) for the glossary and how Agent Skills, MCP, and A2A fit.

## Inside a persona

[**`SKILL.md`**](./specification/#2-skillmd-) provides instructions. [**Definition files**](./specification/#6-definition-files-) describe the data and workflows. The [**registry**](./specification/#5-registry-) pins the Git revision and fingerprint of each linked definition.

Draft 0.1 comes from personas running on **Gabriel Operator**. The [Portable Persona Runtime installer](https://github.com/Gabriel-Operator/portable-persona-runtime) deploys published personas to a self-hosted runtime appliance.
